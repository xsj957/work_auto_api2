# 优惠券规则详解

## 优惠券类型

| 类型 | 说明 | 优惠金额设置 |
|------|------|--------------|
| 满减券 | 满 X 元减 Y 元 | 满 [金额] 元，减 [金额] 元 |
| 现金券 | 固定面额减免 | 固定金额 |
| 折扣券 | 按比例折扣 | 折扣比例 |

## 优惠券配置项

### 基本信息

| 字段 | 说明 | 必填 |
|------|------|------|
| 优惠券类型 | 满减券 / 现金券 / 折扣券 | 是 |
| 优惠金额 | 满减券需设置"满"和"减"金额 | 是 |
| 优惠券名称 | 自定义名称 | 是 |

### 使用设置

| 字段 | 说明 | 备注 |
|------|------|------|
| 用券时间 | 领取后可用的等待期（X 天后可用） | 不设置则领取后立即可用 |
| 可用日期 - 星期 | 星期一 ~ 星期日（可多选） | 控制哪些天可用 |
| 可用日期 - 时间段 | 开始时间 → 结束时间 | 控制具体时间段 |
| 可用日期 - 多条件 | 支持 + 新增条件 | 可设置多个时间段 |
| 有效期 - 固定时间 | 开始日期 → 结束日期 | 绝对时间范围 |
| 有效期 - 相对时间 | 领取后 X 天有效 | 相对领取时间 |

### 适用范围

| 选项 | 说明 |
|------|------|
| 台费 | 可用于抵扣台费 |
| 商品 | 可用于抵扣商品金额 |
| 可多选 | 台费和商品可同时勾选 |

### 库存设置

| 字段 | 说明 |
|------|------|
| 库存数 | 优惠券总数量 |
| 不设置 | 库存不限量 |

### 其他设置

| 字段 | 说明 |
|------|------|
| 使用说明 | 优惠券使用规则说明 |

## 优惠券状态

| 状态 | 说明 | 操作影响 |
|------|------|----------|
| 开启 | 优惠券正常发放和使用 | 可被领取和使用 |
| 关闭 | 暂停发放和使用 | 不可被领取，已领取的仍可使用（取决于配置） |

## 优惠券操作

| 操作 | 说明 | 适用状态 |
|------|------|----------|
| 新增优惠券 | 创建新优惠券，配置完整信息 | - |
| 启用 | 开启优惠券（状态：开启） | 关闭状态 |
| 停用 | 关闭优惠券（状态：关闭） | 开启状态 |
| 删除 | 删除优惠券 | 通常仅未领取的可删除 |
| 发放优惠券 | 在会员管理中向指定会员发放 | 开启状态 |

## 优惠券数据指标

| 指标 | 说明 | 计算公式 |
|------|------|----------|
| 已领取数量 | 已发放给会员的数量 | - |
| 核销数量 | 已使用的数量 | - |
| 核销率 | 使用比例 | 核销数量 / 已领取数量 × 100% |

## 优惠券与支付组合

### 核心规则

#### 1. 抵扣顺序

```
优惠券 → 余额卡（台费卡/储值卡）→ 现金/其他
```

- 优先使用优惠券抵扣
- 剩余金额使用余额卡支付
- 不足部分使用现金或其他支付方式

#### 2. 优惠券适用范围限制

| 优惠券类型 | 可抵扣 | 不可抵扣 |
|------------|--------|----------|
| 商品券 | 商品金额 | 台费、服务费 |
| 台费券 | 台费金额 | 商品、服务费 |
| 通用券 | 台费 + 商品 | 服务费（视配置） |

**关键**：优惠券严格按适用范围抵扣，不跨类型。

#### 3. 余额卡支付范围限制

| 卡类型 | 可支付 | 不可支付 |
|--------|--------|----------|
| 台费卡 (`tfk`) | 仅台费 | 商品、服务费 |
| 储值卡/通用卡 (`czk`) | 台费 + 商品 + 服务费 | 无限制 |

### 组合场景示例

#### 场景 1：商品券 + 台费卡组合支付

**订单构成：**
```
订单总额：10 元
├── 台费：6 元
└── 商品：4 元
```

**使用：** 商品优惠券 4 元 + 台费卡

**第一步：优惠券抵扣**
```
商品：4 - 4 = 0 元（全额抵扣）
台费：6 元（未抵扣）
待支付：6 元（全部是台费）
```

**第二步：台费卡支付**
```
台费卡只能支付台费 ✓
台费剩余：6 元
需要台费卡余额 ≥ 6 元
```

**最终结算单：**

| 费用类型 | 原始金额 | 优惠券抵扣 | 台费卡支付 | 现金 |
|----------|----------|------------|------------|------|
| 台费 | 6 元 | 0 元 | 6 元 | 0 元 |
| 商品 | 4 元 | 4 元 | 0 元 | 0 元 |
| **合计** | **10 元** | **4 元** | **6 元** | **0 元** |

---

#### 场景 2：台费券 + 储值卡组合支付

**订单构成：**
```
订单总额：15 元
├── 台费：10 元
├── 商品：3 元
└── 服务费：2 元
```

**使用：** 台费优惠券 5 元 + 储值卡

**第一步：优惠券抵扣**
```
台费：10 - 5 = 5 元（抵扣 5 元）
商品：3 元（未抵扣）
服务费：2 元（未抵扣）
待支付：10 元
```

**第二步：储值卡支付**
```
储值卡可支付台费 + 商品 + 服务费 ✓
台费：5 元
商品：3 元
服务费：2 元
需要储值卡余额 ≥ 10 元
```

**最终结算单：**

| 费用类型 | 原始金额 | 优惠券抵扣 | 储值卡支付 | 现金 |

| 台费 | 10 元 | 5 元 | 5 元 | 0 元 |
| 商品 | 3 元 | 0 元 | 3 元 | 0 元 |
| 服务费 | 2 元 | 0 元 | 2 元 | 0 元 |
| **合计** | **15 元** | **5 元** | **10 元** | **0 元** |

#### 场景 3：多张优惠券 + 台费卡 + 现金组合

**订单构成：**
```
订单总额：20 元
├── 台费：12 元
└── 商品：8 元
```

**使用：** 
- 商品优惠券 3 元
- 台费优惠券 5 元
- 台费卡余额 4 元
- 现金补齐

**第一步：优惠券抵扣**
```
商品：8 - 3 = 5 元（商品券抵扣 3 元）
台费：12 - 5 = 7 元（台费券抵扣 5 元）
待支付：12 元
```

**第二步：台费卡支付**
```
台费卡只能支付台费 ✓
台费剩余：7 元
台费卡余额：4 元
台费卡支付：4 元
台费还需：7 - 4 = 3 元
```

**第三步：现金补齐**
```
台费剩余：3 元 → 现金支付
商品剩余：5 元 → 现金支付
现金合计：8 元
```

**最终结算单：**

| 费用类型 | 原始金额 | 优惠券抵扣 | 台费卡支付 | 现金 |
|----------|----------|------------|------------|------|
| 台费 | 12 元 | 5 元 | 4 元 | 3 元 |
| 商品 | 8 元 | 3 元 | 0 元 | 5 元 |
| **合计** | **20 元** | **8 元** | **4 元** | **8 元** |

#### 场景 4：5元商品+台费现金券 + 台费卡（通用券按比例分摊）

**订单构成：**
```
订单总额：25 元
├── 台费：20 元
└── 商品：5 元
```

**使用：** 5元商品+台费现金券（scope=["1","2"]）+ 台费卡

**第一步：优惠券按比例分摊**
```
台费占比 = 20 / 25 = 80%
商品占比 = 5 / 25 = 20%
台费分摊 = 5 × 80% = 4.00 元
商品分摊 = 5 × 20% = 1.00 元

台费待付 = 20 - 4 = 16.00 元
商品待付 = 5 - 1 = 4.00 元
```

**第二步：台费卡支付台费**
```
台费卡只能支付台费 ✓
台费待付：16 元
需要台费卡余额 ≥ 16 元
```

**第三步：商品待付用微信（台费卡不能付商品！）**
```
⚠️ 台费卡不能支付商品！
商品待付：4 元 → 必须用微信/现金/通用卡补齐
```

**最终结算单：**

| 费用类型 | 原始金额 | 优惠券抵扣 | 台费卡支付 | 微信/现金 |
|----------|----------|------------|------------|-----------|
| 台费 | 20 元 | 4 元 | 16 元 | 0 元 |
| 商品 | 5 元 | 1 元 | 0 元 | 4 元 |
| **合计** | **25 元** | **5 元** | **16 元** | **4 元** |

**注意**：通用券（scope=["1","2"]）按台费和商品金额比例分摊，不是全额抵扣某一类。台费卡只付台费部分，商品待付 4 元必须用微信补齐。

#### 场景 5：优惠券面额大于对应费用

**订单构成：**
```
订单总额：8 元
├── 台费：3 元
└── 商品：5 元
```

**使用：** 商品优惠券 8 元（面额 > 商品金额）

**抵扣规则：**
```
商品：5 - 5 = 0 元（最多抵扣商品全额）
台费：3 元（商品券不能抵扣台费）
优惠券剩余：8 - 5 = 3 元（作废，不退不跨类型）

```

| 费用类型 | 原始金额 | 优惠券抵扣 | 实际支付 |
|----------|----------|------------|----------|
| 台费 | 3 元 | 0 元 | 3 元 |
| 商品 | 5 元 | 5 元 | 0 元 |
| **合计** | **8 元** | **5 元** | **3 元** |

**注意**：优惠券超出部分 3 元不跨类型抵扣，直接作废。

**订单构成：**

### 边界情况处理

| 情况 | 处理方式 |
|------|----------|
| 优惠券过期 | 不可使用，需选择其他支付方式 |
| 优惠券库存为 0 | 不可领取，已持有的仍可使用 |
| 会员余额不足 | 提示充值或选择其他支付方式 |

| 优惠券 + 会员折扣 | 先扣优惠券，再应用会员折扣 |

## 优惠券分配规则（台费 vs 商品）

> 以下示例基于：普通台费 = 38.90 元，商品 = 5.00 元

scope 取值：`"1"` = 台费，`"2"` = 商品

| 编号 | 场景 | 券优惠分配 | 预期台费卡 | 预期其他待付 |
|------|------|------------|------------|--------------|
| T01 | 不使用优惠券 | 台费0、商品0 | 38.90 | 5.00 |
| T02 | 5元仅商品现金券 scope=["2"] | 台费0、商品5.00 | 38.90 | 0.00 |
| T03 | 商品8折券 scope=["2"] | 台费0、商品1.00 | 38.90 | 4.00 |
| T04 | 5元仅台费现金券 scope=["1"] | 台费5.00、商品0 | 33.90 | 5.00 |
| T05 | 台费8折券 scope=["1"] | 台费7.78、商品0 | 31.12 | 5.00 |
| T06 | 5元台费+商品现金券 scope=["1","2"] | 台费4.43、商品0.57 | 34.47 | 4.43 |
| T07 | 台费券完全抵完台费 | 台费38.90 | 0.00 | 5.00 |
| T08 | 两张可叠加商品现金券，各2元 | 商品共4.00 | 38.90 | 1.00 |
| T09 | 台费卡只有20，通用卡18.90，使用5元商品券 | 商品5.00 | 20.00 | 0.00，通用卡抵18.90 |
| T10 | 桌台禁止余额支付，使用5元商品券 | 商品5.00 | 0.00 | 38.90 |
| T11 | 纯商品订单使用商品现金券 | 商品按券抵扣 | 0.00 | 商品券后金额 |
| T12 | 纯台费订单使用商品券 | 应提示优惠金额为0 | 不进入余额结果 | 保持原校验 |

### 分配规则要点

1. **台费券只抵扣台费**：scope=["1"] 的券只从台费金额中扣除，不影响商品部分
2. **商品券只抵扣商品**：scope=["2"] 的券只从商品金额中扣除，不影响台费部分
3. **通用券按比例分配**：scope=["1","2"] 的券按台费和商品金额比例分配抵扣（如 T06：台费占比 38.90/43.90 ≈ 88.6%，商品占比 11.4%）
4. **可叠加券分别计算**：多张可叠加券各自在自己的范围内独立抵扣，总抵扣额为各券之和（如 T08）
5. **券面额 > 对应费用**：券最多抵扣到对应费用归零，超出部分作废，不跨类型补偿（如 T12）
6. **桌台禁止余额支付**：台费卡余额不可用，台费需全额现金/其他支付（如 T10）
7. **卡余额不足**：台费卡余额不够时，剩余台费转通用卡或现金补齐（如 T09）

## 练球台费场景

> 以下示例基于：普通台费 = 30.00 元，练球台费 = 10.00 元，商品 = 5.00 元，仅台费现金券 = 5.00 元

| 编号 | 门店设置 | 预期结果 |
|------|----------|----------|
| T13 | 练球允许余额支付 | `allFeePrice=40`、`trainingPrice=10`、台费卡抵扣35、商品待付5 |
| T14 | 练球禁止余额支付 | 台费卡只抵普通台费券后金额25，练球10和商品5待付 |
| T15 | 台费券计算范围 | 5元券只能抵普通台费，不得分摊到10元练球台费 |

### 练球台费规则要点

1. **练球台费与普通台费分离计算**：`allFeePrice` 为全部台费合计，`trainingPrice` 为练球台费部分
2. **练球允许余额支付**：台费卡可抵扣全部台费（含练球），券先抵扣普通台费，剩余由台费卡支付
3. **练球禁止余额支付**：台费卡只能抵扣普通台费部分，练球台费需现金/其他支付
4. **台费券只作用于普通台费**：即使券的 scope 包含台费，也不得将抵扣额分摊到练球台费上（T15）

## 合并结账场景

| 编号 | 场景 | 验证点 |
|------|------|--------|
| T16 | 一笔商品券订单 + 一笔无券订单 | 两笔订单的台费都能进入台费卡计算 |
| T17 | 两笔订单共享有限台费卡余额 | 第一笔抵扣后必须扣减卡内余额，第二笔不能重复使用 |
| T18 | 一笔台费券 + 一笔商品券 | 每笔订单按各自券范围计算，汇总金额等于分笔之和 |
| T19 | 多张同类型可叠加券 | `allFeePrice` 只能统计一次，不能按券数量翻倍 |

### 合并结账规则要点

1. **台费独立于优惠券计算**：无论订单是否使用优惠券，所有订单的台费汇总后统一进入台费卡计算（T16）
2. **卡余额共享且实时扣减**：多笔订单共用同一张台费卡时，先结算的订单扣减余额后，后续订单只能使用剩余余额（T17）
3. **各订单券范围互不干扰**：不同订单使用的不同类型券，各自在自己的范围内独立计算，汇总结果等于逐笔计算之和（T18）
4. **可叠加券金额不重复统计基数**：多张同类型券叠加时，抵扣金额累加，但计费基数（如 `allFeePrice`）只计一次，不因券数量翻倍（T19）
