# 优惠券规则详解

## 优惠券类型

| 类型 | 说明 | 优惠金额设置 |
|------|------|--------------|
| 满减券 | 满 X 元减 Y 元 | 满 [金额] 元，减 [金额] 元 |
| 现金券 | 固定面额减免 | 固定金额 |
| 折扣券 | 按比例折扣 | 折扣比例 |

## 优惠券配置项

### 基本信息

| 字段 | 说明 | 必填 |
|------|------|------|
| 优惠券类型 | 满减券 / 现金券 / 折扣券 | 是 |
| 优惠金额 | 满减券需设置"满"和"减"金额 | 是 |
| 优惠券名称 | 自定义名称 | 是 |

### 使用设置

| 字段 | 说明 | 备注 |
|------|------|------|
| 用券时间 | 领取后可用的等待期（X 天后可用） | 不设置则领取后立即可用 |
| 可用日期 - 星期 | 星期一 ~ 星期日（可多选） | 控制哪些天可用 |
| 可用日期 - 时间段 | 开始时间 → 结束时间 | 控制具体时间段 |
| 可用日期 - 多条件 | 支持 + 新增条件 | 可设置多个时间段 |
| 有效期 - 固定时间 | 开始日期 → 结束日期 | 绝对时间范围 |
| 有效期 - 相对时间 | 领取后 X 天有效 | 相对领取时间 |

### 适用范围

| 选项 | 说明 |
|------|------|
| 台费 | 可用于抵扣台费 |
| 商品 | 可用于抵扣商品金额 |
| 可多选 | 台费和商品可同时勾选 |

### 库存设置

| 字段 | 说明 |
|------|------|
| 库存数 | 优惠券总数量 |
| 不设置 | 库存不限量 |

### 其他设置

| 字段 | 说明 |
|------|------|
| 使用说明 | 优惠券使用规则说明 |

## 优惠券状态

| 状态 | 说明 | 操作影响 |
|------|------|----------|
| 开启 | 优惠券正常发放和使用 | 可被领取和使用 |
| 关闭 | 暂停发放和使用 | 不可被领取，已领取的仍可使用（取决于配置） |

## 优惠券操作

| 操作 | 说明 | 适用状态 |
|------|------|----------|
| 新增优惠券 | 创建新优惠券，配置完整信息 | - |
| 启用 | 开启优惠券（状态：开启） | 关闭状态 |
| 停用 | 关闭优惠券（状态：关闭） | 开启状态 |
| 删除 | 删除优惠券 | 通常仅未领取的可删除 |
| 发放优惠券 | 在会员管理中向指定会员发放 | 开启状态 |

## 优惠券数据指标

| 指标 | 说明 | 计算公式 |
|------|------|----------|
| 已领取数量 | 已发放给会员的数量 | - |
| 核销数量 | 已使用的数量 | - |
| 核销率 | 使用比例 | 核销数量 / 已领取数量 × 100% |

## 筛选查询

| 筛选项 | 类型 | 说明 |
|--------|------|------|
| 优惠券名称 | 模糊搜索 | 输入关键词搜索 |
| 优惠券类型 | 下拉选择 | 满减券/现金券/折扣券 |
| 优惠券状态 | 下拉选择 | 开启 / 关闭 |

## 优惠券与支付组合

### 核心规则

#### 1. 抵扣顺序

```
优惠券 → 余额卡（台费卡/储值卡）→ 现金/其他
```

- 优先使用优惠券抵扣
- 剩余金额使用余额卡支付
- 不足部分使用现金或其他支付方式

#### 2. 优惠券适用范围限制

| 优惠券类型 | 可抵扣 | 不可抵扣 |
|------------|--------|----------|
| 商品券 | 商品金额 | 台费、服务费 |
| 台费券 | 台费金额 | 商品、服务费 |
| 通用券 | 台费 + 商品 | 服务费（视配置） |

**关键**：优惠券严格按适用范围抵扣，不跨类型。

#### 3. 余额卡支付范围限制

| 卡类型 | 可支付 | 不可支付 |
|--------|--------|----------|
| 台费卡 (`tfk`) | 仅台费 | 商品、服务费 |
| 储值卡/通用卡 (`czk`) | 台费 + 商品 + 服务费 | 无限制 |

---

### 组合场景示例

#### 场景 1：商品券 + 台费卡组合支付

**订单构成：**
```
订单总额：10 元
├── 台费：6 元
└── 商品：4 元
```

**使用：** 商品优惠券 4 元 + 台费卡

**第一步：优惠券抵扣**
```
商品：4 - 4 = 0 元（全额抵扣）
台费：6 元（未抵扣）
待支付：6 元（全部是台费）
```

**第二步：台费卡支付**
```
台费卡只能支付台费 ✓
台费剩余：6 元
需要台费卡余额 ≥ 6 元
```

**最终结算单：**

| 费用类型 | 原始金额 | 优惠券抵扣 | 台费卡支付 | 现金 |
|----------|----------|------------|------------|------|
| 台费 | 6 元 | 0 元 | 6 元 | 0 元 |
| 商品 | 4 元 | 4 元 | 0 元 | 0 元 |
| **合计** | **10 元** | **4 元** | **6 元** | **0 元** |

---

#### 场景 2：台费券 + 储值卡组合支付

**订单构成：**
```
订单总额：15 元
├── 台费：10 元
├── 商品：3 元
└── 服务费：2 元
```

**使用：** 台费优惠券 5 元 + 储值卡

**第一步：优惠券抵扣**
```
台费：10 - 5 = 5 元（抵扣 5 元）
商品：3 元（未抵扣）
服务费：2 元（未抵扣）
待支付：10 元
```

**第二步：储值卡支付**
```
储值卡可支付台费 + 商品 + 服务费 ✓
台费：5 元
商品：3 元
服务费：2 元
需要储值卡余额 ≥ 10 元
```

**最终结算单：**

| 费用类型 | 原始金额 | 优惠券抵扣 | 储值卡支付 | 现金 |
|----------|----------|------------|------------|------|
| 台费 | 10 元 | 5 元 | 5 元 | 0 元 |
| 商品 | 3 元 | 0 元 | 3 元 | 0 元 |
| 服务费 | 2 元 | 0 元 | 2 元 | 0 元 |
| **合计** | **15 元** | **5 元** | **10 元** | **0 元** |

---

#### 场景 3：多张优惠券 + 台费卡 + 现金组合

**订单构成：**
```
订单总额：20 元
├── 台费：12 元
└── 商品：8 元
```

**使用：** 
- 商品优惠券 3 元
- 台费优惠券 5 元
- 台费卡余额 4 元
- 现金补齐

**第一步：优惠券抵扣**
```
商品：8 - 3 = 5 元（商品券抵扣 3 元）
台费：12 - 5 = 7 元（台费券抵扣 5 元）
待支付：12 元
```

**第二步：台费卡支付**
```
台费卡只能支付台费 ✓
台费剩余：7 元
台费卡余额：4 元
台费卡支付：4 元
台费还需：7 - 4 = 3 元
```

**第三步：现金补齐**
```
台费剩余：3 元 → 现金支付
商品剩余：5 元 → 现金支付
现金合计：8 元
```

**最终结算单：**

| 费用类型 | 原始金额 | 优惠券抵扣 | 台费卡支付 | 现金 |
|----------|----------|------------|------------|------|
| 台费 | 12 元 | 5 元 | 4 元 | 3 元 |
| 商品 | 8 元 | 3 元 | 0 元 | 5 元 |
| **合计** | **20 元** | **8 元** | **4 元** | **8 元** |

---

#### 场景 4：优惠券面额大于对应费用

**订单构成：**
```
订单总额：8 元
├── 台费：3 元
└── 商品：5 元
```

**使用：** 商品优惠券 8 元（面额 > 商品金额）

**抵扣规则：**
```
商品：5 - 5 = 0 元（最多抵扣商品全额）
台费：3 元（商品券不能抵扣台费）
优惠券剩余：8 - 5 = 3 元（作废，不退不跨类型）
待支付：3 元（台费）
```

**最终结算单：**

| 费用类型 | 原始金额 | 优惠券抵扣 | 实际支付 |
|----------|----------|------------|----------|
| 台费 | 3 元 | 0 元 | 3 元 |
| 商品 | 5 元 | 5 元 | 0 元 |
| **合计** | **8 元** | **5 元** | **3 元** |

**注意**：优惠券超出部分 3 元不跨类型抵扣，直接作废。

---

#### 场景 5：台费卡余额不足

**订单构成：**
```
订单总额：10 元
└── 台费：10 元
```

**使用：** 台费卡（余额仅 6 元）

**处理方式：**
```
台费：10 元
台费卡余额：6 元
台费卡支付：6 元
台费还需：10 - 6 = 4 元 → 需其他支付方式补齐
```

**允许组合补齐：** 台费卡不足部分可用现金或储值卡支付。

---

### 支付组合矩阵

| 优惠券类型 | 台费卡 | 储值卡 | 现金 | 是否可行 |
|------------|--------|--------|------|----------|
| 商品券 | ✓ | ✓ | ✓ | 商品券只抵扣商品，其余用支付卡/现金 |
| 台费券 | ✓ | ✓ | ✓ | 台费券只抵扣台费，其余用支付卡/现金 |
| 商品券 + 台费券 | ✓ | ✓ | ✓ | 分别抵扣对应费用 |
| 仅台费卡 | - | - | ✓ | 台费卡只付台费，商品需现金 |
| 仅储值卡 | - | - | ✓ | 储值卡可付全部 |

### 接口参数说明（含优惠券）

```json
POST /merchant-api/pay/order/submit

{
  "id": pay_order_id,
  "channelCode": "czk",
  "channelExtras": {
    "flow_type": "1",
    "extra": {
      "orderType": "桌台订单",
      "orderNo": order_no,
      "price": "10.00",
      "couponPrice": "4.00",
      "couponName": "商品 4 元券",
      "givePrice": "0",
      "TfkGivenPrice": "0",
      "storeNo": STORE_NO
    },
    "golfer_no": golfer_no,
    "channelCode": "czk"
  }
}
```

**关键字段：**
- `couponPrice`：优惠券抵扣金额
- `couponName`：使用的优惠券名称
- `price`：订单总金额（优惠券抵扣前）
- `givePrice`：赠送金额

### 边界情况处理

| 情况 | 处理方式 |
|------|----------|
| 优惠券过期 | 不可使用，需选择其他支付方式 |
| 优惠券库存为 0 | 不可领取，已持有的仍可使用 |
| 会员余额不足 | 提示充值或选择其他支付方式 |
| 台费卡支付商品 | 不允许，需切换到储值卡或现金 |
| 多张优惠券叠加 | 取决于系统配置（通常可叠加） |
| 优惠券 + 会员折扣 | 先扣优惠券，再应用会员折扣 |
