# 会员管理规则详解

## 会员信息字段

| 字段 | 说明 |
|------|------|
| 会员 ID | 系统唯一标识 |
| 姓名 | 会员真实姓名 |
| 会员昵称 | 自定义昵称 |
| 手机号 | 登录和识别的主要标识 |
| 会员等级 | 普通会员等（可配置等级体系） |
| 累计消费金额 | 历史消费总额 |
| 总余额 | 通用卡 + 台费卡的总余额 |
| 通用卡余额 | 储值卡余额（可支付台费+商品+服务费） |
| 台费卡余额 | 仅用于支付台费 |
| 优惠券数量 | 持有的优惠券数量 |

## 会员等级

- **普通会员**：默认等级
- 可配置多级会员体系（银卡、金卡、钻石等）
- 不同等级可享受不同折扣和权益

## 余额类型

```
总余额 = 通用卡余额 + 台费卡余额
```

| 类型 | 代码 | 支付范围 | 说明 |
|------|------|----------|------|
| 通用卡 | `czk` | 台费 + 商品 + 服务费 | 储值卡，用途广泛 |
| 台费卡 | `tfk` | 仅台费 | 专用卡，限制较多 |

## 会员操作

### 基础操作

| 操作 | 说明 | 场景 |
|------|------|------|
| 详情 | 查看会员详细信息 | 了解会员余额、等级、消费记录 |
| 新增会员 | 创建新会员 | 新顾客注册 |
| 修改等级 | 调整会员等级 | 升级/降级会员 |

### 余额相关

| 操作 | 说明 | 注意事项 |
|------|------|----------|
| 储值 | 为会员充值（通用卡或台费卡） | 需选择充值类型 |
| 调余额 | 手动调整会员余额 | 需谨慎操作，有审计记录 |

### 营销相关

| 操作 | 说明 | 场景 |
|------|------|------|
| 发券 | 向会员发放优惠券 | 营销活动、会员关怀 |
| 加入黑名单 | 将会员加入黑名单 | 违规会员限制 |

### 批量操作

| 操作 | 说明 | 场景 |
|------|------|------|
| 会员导入 | 批量导入会员数据 | 系统迁移、批量注册 |

## 会员与桌台绑定

### 绑定流程

```
1. 查询会员（golfer/pageV2）
   - 搜索条件：手机号/会员昵称
   - 返回：golferNo, golferName, totalBalance, deskBalance

2. 绑定会员到桌台（desk/addGolfer）
   - 参数：deskNo, golferNoList
   - 一个桌台可绑定多个会员
```

### 绑定影响

- 绑定后可使用余额支付（储值卡/台费卡）
- 订单关联会员信息，便于积分和优惠计算
- 可查询会员在该桌台的消费记录

## 会员查询接口

### 分页查询会员

```
POST /merchant-api/store/golfer/pageV2

参数：
{
  "storeNo": STORE_NO,
  "pageNo": 1,
  "pageSize": 10,
  "searchName": "手机号或昵称",
  "filter": {"storeNo": STORE_NO}
}

返回：
{
  "list": [
    {
      "golferNo": "会员ID",
      "golferName": "姓名",
      "totalBalance": 1000.00,  // 总余额
      "deskBalance": 1000.00,   // 台费卡余额
      "golferLevel": "普通会员",
      "consumeAmount": 0.00     // 累计消费
    }
  ]
}
```

## 会员数据来源

- **业务数据配置**：`config/config.yaml` 中的 `business_data` 或 `payment_test`
- **不允许硬编码**：会员手机号等信息从配置读取
- **测试会员**：使用配置中指定的测试会员账号
